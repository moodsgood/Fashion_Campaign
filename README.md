# 💡 使用小贴士（欢迎交流v：Moodsgood）

## 使用前

1. **图片优先**：尽量上传清晰的产品白底实拍图、细节特写图，图片越完整，产品识别越准确，减少服饰结构错误。
2. **补充信息效果更佳**：可以附带说明面料、填充物、工艺、目标客群、品牌系列等信息；没有的信息无需编造，技能不会凭空虚构参数。
3. **触发技能**：上传服装图片后，输入触发词，例如：`做新品Campaign`、`给这件衣服做公众号品宣`，即可启动完整流程；单纯抠图、换背景不会运行全套 10 页流程。

## 使用过程中

1. **产品纠错机制**：如果 AI 生成的衣服结构出错（袖口、领型、口袋、绗缝等不对），直接用文字指出问题，**一次修正全局生效**，后续所有页面、Banner 都会自动沿用修正，不用重复描述。
2. **分页生成**：方案确认完成后，输入 `生成01`、`继续02` 即可逐张产出画面，每次只生成单张独立页面，不会把多页拼在一张图里。
3. **防盗版模式**：担心款式被抄袭，可以直接指令：`开启防盗版模式`。会使用局部裁切、特写、遮挡视角，不展示完整版型，同时保留质感与品牌氛围。
4. **公众号封面 Banner**：全部内页完成后，输入 `做Banner` / `公众号封面`，自动生成 2.34:1 适配公众号的封面图，会重新构图，不会直接裁切内页。

## 注意避坑

1. 本 Skill**严禁 AI 幻觉**，不会自动编造克重、蓬松度、防水等级、专利、检测报告等数据，没有提供就不会输出。
2. 文案默认高级品牌编辑风，如果想要淘宝电商叫卖风格，需要你主动说明。
3. 没有的服装结构不会强行生成，比如衣服没有毛领，就不会产出毛领相关页面。

## 仓库部署 & 导入提醒

1. `Fashion_Campaign_服装新品品宣_SKILL.md` **必须放在仓库根目录，不要放进子文件夹**，否则导入 Skill 会读取失败。
2. 更新 Skill 规则后，重新复制仓库链接导入，加载最新版本。
3. 请勿上传包含密钥、个人隐私的文件到 GitHub 仓库。
